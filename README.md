# Boat-Motor-Control-

The software (XXXXXX.ino) is written in arduino C language. The Arduino IDE used was the

1.8.18 version. The software  handles the control of the 2 motors of the boat (propeller and rudder) 

and the communication with the android application (smartphone). For the propeller motor 

the program handles the operation of the H-bridge H/W, used to move the motor in both directions 

nd controls its speed via a PWM pulse generated by the ESP32 microcontroller. The rudder servo

motor is controlled via pulses generated by ESP32. Finally the software receives one byte

commands from the android Serial Bluetooth Terminal application for the various actions on

the motors and forwards certain information to it (e.g. propeller motor speed, rudder servo 

motor position etc.). 





The addition of a solar panel makes the vessel autonomous in power. The solar

panel is  connected to the battery via a TP4056 charging module which charges the battery 

continuously as long as there is sunlight and ensures safe charging of the Li-ion battery.
